#  YB-SneakerStudios 👞

A modern React-based sneaker store UI built with Tailwind CSS — minimal, responsive, and designed for style.



##  Features

* Tailwind CSS 
* Modular React Componants and Sections
* Modern sneaker showcase layout
* Responsive design, optimized for all devices

## Getting Started

### 1. Clone the Repo

```bash
git clone https://github.com/Yash-Bandal/YB-SneakerStudios.git
cd YB-SneakerStudios
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Run the App

```bash
npm run dev
```

---
> Make sure you have [Node.js](https://nodejs.org/), [Tailwind](http://tailwindcss.com/) and [Vite](https://vitejs.dev/) set up.
